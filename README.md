# Techverse Infotech - Landing Website

Ultra-high-end enterprise software & AI engineering landing website built with **React**, **Next.js 14 (App Router)**, **GSAP 3**, and **Lenis Smooth Scroll**, engineered for performance and SEO visibility.

---

## 🚀 Quick Start

From the `techverse-web` folder:

```bash
# 1. Run development server
npm run dev

# 2. Build for production
npm run build

# 3. Start production server
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

---

## 💎 Features & Animation Physics

- **Dynamic Per-Grapheme Title Sweep**: Violet-to-fuchsia color wave across heading characters synchronized with scroll progress.
- **3D Arc Cylindrical Perspective Carousel**: Interactive drag-and-throw inertia physics with velocity decay, auto-wrap boundary, and custom cursor badge.
- **Kinetic Scroll-Scrubbed Text Reveal**: Paragraph opacity scrubbing with popping floating status badges (*Enterprise-Grade Architecture*, *AI-Native Workflows*, *Allergic to Mediocrity*).
- **SVG Gooey Filter & Panoramic Mesh**: Liquid metaball filter effects behind interactive feature cards.
- **Floating Glassmorphic Bottom Dock Navigation**: Floating pill navbar with frosted blur backdrop and expandable mobile navigation drawer.
- **Lenis 1.3 Smooth Scroll**: Inertia scrolling synchronized with GSAP ScrollTrigger.

---

## 🔍 SEO & Technical Architecture

- **Next.js 14 App Router**: Server-side rendering (SSR) and full static page generation.
- **Dynamic Sitemap**: Automatically generated `sitemap.xml` with priority indices.
- **Dynamic Robots**: Configured `robots.txt` with sitemap referencing.
- **Rich JSON-LD Structured Data**: Embedded multi-schema (`Organization`, `ProfessionalService`, `WebSite`, `FAQPage`) for Google rich search results.
- **OpenGraph & Twitter Cards**: High-resolution social sharing cards configured with `techverse-logo.jpg`.
- **WCAG Accessibility**: Full ARIA roles, focus management, semantic headings (`h1`, `h2`, `h3`), and responsive typography.
